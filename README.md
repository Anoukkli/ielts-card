# 雅思复习 PWA

手机上背单词、刷错题、练写作的离线网页。数据来自 Notion（`deck.json`）和本地写作库（`writing.json`），进度存在本机浏览器，**不联网、不花 API 费用**。

## 部署到 GitHub Pages（5 分钟，只做一次）

1. 打开 <https://github.com/new>，Repository name 填 `ielts-card`，选 **Public**，点 Create。
2. 进入新仓库，点 **uploading an existing file**，把本文件夹里这几个文件拖进去：
   - `index.html`
   - `writing.js`
   - `writing.json`
   - `deck.json`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `.nojekyll`（没有就跳过）
3. 点 **Commit changes**。
4. 仓库 `Settings` → 左侧 `Pages` → Source 选 **Deploy from a branch** → Branch 选 `main` / `(root)` → Save。
5. 等 1–2 分钟，页面顶部会出现网址：`https://<你的用户名>.github.io/ielts-card/`

## 装到 iPhone 主屏

1. 用 **Safari** 打开上面的网址（不要用微信打开）。
2. 点底部 **分享** → **添加到主屏幕** → 添加。
3. 之后从主屏图标进入，全屏、无地址栏，和 App 一样。

首次打开需要联网加载一次，之后 Service Worker 会缓存，**飞行模式也能背**。

## 每天怎么用

- 首页显示「今日待背」张数（默认 20，可在设置里改）
- 点卡片翻面 → 看释义、原文例句、搭配
- 三个按钮：**不会**（明天再来）/ **模糊**（保持间隔）/ **会了**（间隔 ×2）
- 背满 20 张，首页变成「今日已完成」，当天不再出题
- 「刷错题」是独立队列：先看题干，翻面看答案和当时错在哪，标「会了 / 还是错」

## 写作 45 分钟（v5 新增）

首页第三块「写作 45 分钟」，进去按顺序做四块，右上角有总计时：

| 块 | 时长 | 在做什么 | 练什么 |
| --- | --- | --- | --- |
| 语法中译英 | 15 min | 看中文 + 提示词，打字写英文，对照后自评 | 冠词 / 主谓一致 / 时态 / 被动 / 倍数 / 从句 / 非谓语 / 搭配 |
| 小作文骨架 | 10 min | 按「总述三句式」等骨架任务写 2–3 句，对照参考 | Task 1 的固定套路，不是临场造句 |
| 大作文逻辑 | 15 min | 立场 → 两个分论点 → 展开第一个（原因 / 例子 / 回扣） | 论点链，专治「有观点但展不开」 |
| 复盘 | 5 min | 按模块进入（语法 / 小作文 / 大作文 / 观点），每条可存打磨版 | 纠错闭环 |

题库有两层：**48 句语法 + 11 条小作文直接来自本人原文**（折线图/柱状图/饼图/两张表格），会优先出题；其余 60 句语法和 2 条小作文（流程、地图）是通用补充。

规则：

1. **对照不是判卷。** 词级重合率只说明「和参考差多远」，语法对不对还是你自己判；所以自评按钮只有三个：写对了 / 差一点 / 不会。
2. **语法题循环出。** 今天写错的，1–2 天后会再出现；写对的按 1/2/4/7/15/30 天往后推。
3. **大作文不写全文。** 一题只练「审题 → 立场 → 论点链」，全文留给周末整篇模拟，否则每天 45 分钟不够。
4. **复盘按模块走。** 写作首页「复盘」先选块，再逐条打磨；一条能存两版：你当时写的、打磨后的。
5. **打磨要落到句子。** 「下次注意」没用，「把 the 补上」才有用。

### 我怎么批改

写作记录存在本机，导出方式：写作首页 → **导出写作记录**，得到 `ielts-writing-日期.json`，发给我。我会按「原句 → 最小修改 → 错因 → 一句话规则」回填，并把反复出现的错因（冠词、比较结构、中式搭配）整理成下一批语法题。

> 导出文件里 `logs` 是按天记的，`srs` 是每个句子的间隔状态，`days` 是每天做了哪几块。

### 加练（不计入四块）

写作首页底部有两个短练习，适合「今天不想写整篇」的时候做：

- **主体段专项（10 分钟计时）**：只写主体段 1，按「主题句 → 原因 → 例子 → 回扣」四问自检，再看参考段落。题目来自大作文题库。
- **观点速练（3 题）**：90 秒内想两个论点，再看观点库的论点、理由、例子。练「有话说」，不写整篇。题库 16 个话题，按间隔重复回来。

## 句型卡（单独一个入口）

首页「句型卡」，与背单词、写作分开计进度。两件事：

1. **模板句型**：12 个 Task 1 骨架（动态图 5、静态图 4、表格 3），每个骨架换 **3 个不同主题**（教育/环境/科技/交通/酒店…）各写一遍。练的是「结构不变、内容随便换」，不是背某一篇。
2. **词汇升级**：40 条基础 → 高级映射（increase a lot → surge、important → crucial、because → due to…），题干给中文情境和基础表达，你要写出用高级版的完整句子。

每天的节奏：**1 个句型（3 个主题）+ 8 条升级**，约 15 分钟。写错的按 1–2 天回来，写对的按 1/2/4/7/15/30 天往后推。

句型卡的进度键是 `ielts.pat.v1`，和单词的 `ielts.srs.v2`、写作的 `ielts.write.v1` 互不影响，清一项不会丢另一项。

## 手机和电脑怎么合并

进度存在**各自浏览器**里，不会自动同步。两边都练过的，用「全量导出 + 导入合并」：

1. 电脑上打开同一个网址，设置 → **全量导出**，得到 `ielts-all-日期.json`。
2. 把文件传到手机（微信文件传输 / 隔空投送 / 存到「文件」）。
3. 手机上打开 PWA → 设置 → **导入并合并** → 选这个文件。

合并规则：同一张卡阶段高的赢；日志取并集；打磨版保留；同一天的完成数取大的。**不会覆盖**手机上已有的进度，重复导入也不会产生重复记录。

> iOS 主屏 PWA 的存储和 Safari 是分开的，导入要在你平时用的那个图标里做。

## 更新词库

我在本地跑 `python notion-kit/sync_deck.py` 重新生成 `deck.json`，然后：

**方法一（网页）**：仓库里点开 `deck.json` → 右上铅笔图标 → 全选删掉 → 粘贴新内容 → Commit。
**方法二（git）**：`git clone` 一次，之后 `copy deck.json` + `git commit + push`。

进度不会丢：进度在手机浏览器里，换 `deck.json` 不影响。

写作题库更新同理：改 `writing.json` 后重新部署，并把 `sw.js` 里的 `CACHE` 版本号 +1，手机才会拿到新文件。

## 几个技术细节

- 发音用系统 TTS（iOS 的英文语音），不需要联网
- 间隔算法：不会 → 明天；模糊 → 按当前阶段；会了 → 1/2/4/7/15/30/60 天
- 写作题对照用词级 LCS 比对，只标「漏了哪些词 / 多了哪些词」，不判语法
- 进度导出：设置 → 导出进度 JSON（可发给我合回 Notion）
- 换手机/清缓存会丢进度，**建议每周导出一次**
