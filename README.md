# 雅思复习 PWA

手机上背单词、刷错题、练写作的离线网页。数据来自 Notion（`deck.json`）和本地写作库（`writing.json`），进度存在本机浏览器，**不联网、不花 API 费用**。

## 部署到 GitHub Pages（5 分钟，只做一次）

1. 打开 <https://github.com/new>，Repository name 填 `ielts-card`，选 **Public**，点 Create。
2. 进入新仓库，点 **uploading an existing file**，把本文件夹里这几个文件拖进去：
   - `index.html`
   - `writing.js`
   - `writing.json`
   - `translate.json`
   - `essay.js`
   - `essay.json`
   - `ideas.js`
   - `ideas.json`
   - `cloze.json`
   - `upgrade.json`
   - `deck.json`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `.nojekyll`（没有就跳过）
3. 点 **Commit changes**。
4. 仓库 `Settings` → 左侧 `Pages` → Source 选 **Deploy from a branch** → Branch 选 `main` / `(root)` → Save。
5. 等 1–2 分钟，页面顶部会出现网址：`https://<你的用户名>.github.io/ielts-card/`

## 装到 iPhone 主屏

1. 用 **Safari** 打开上面的网址（不要用微信打开）。
2. 点底部 **分享** → **添加到主屏幕** → 添加。
3. 之后从主屏图标进入，全屏、无地址栏，和 App 一样。

首次打开需要联网加载一次，之后 Service Worker 会缓存，**飞行模式也能背**。

## 每天怎么用

- 首页显示「今日待背」张数（默认 20，可在设置里改）
- 点卡片翻面 → 看释义、原文例句、搭配
- 三个按钮：**不会**（明天再来）/ **模糊**（保持间隔）/ **会了**（间隔 ×2）
- 背满 20 张，首页变成「今日已完成」，当天不再出题
- 「刷错题」分听力、阅读两个 tab，按题型筛，页面上直接看「最常错」的 3 个题型 × 错因组合和对策。每轮最多 20 题，连续答对 2 次才移出队列，答错 2 天后再来；刷错题不占背单词的每日配额。
  - 卡片正面是题干和选项，遮住答案重做；选择、判断题点选项即作答。
  - 听力题用系统语音读定位句：听、慢速、连前一句听，填空类要把听到的答案写出来再翻面。前提是这条错题的「原文定位」是一句干净的英文。
  - 背面分层展开：前一句（干扰）→ 定位句 → 同义替换 → 信号词 / 干扰项 → 当时为什么错 → 下次动作。旧数据没有的字段不显示，等同原来的版式。

## 写作 45 分钟（v5 新增）

首页第三块「写作 45 分钟」，进去按顺序做四块，右上角有总计时：

| 块 | 时长 | 在做什么 | 练什么 |
| --- | --- | --- | --- |
| 语法中译英 | 15 min | 看中文 + 提示词，打字写英文，对照后自评 | 冠词 / 主谓一致 / 时态 / 被动 / 倍数 / 从句 / 非谓语 / 搭配 |
| 小作文骨架 | 10 min | 按「总述三句式」等骨架任务写 2–3 句，对照参考 | Task 1 的固定套路，不是临场造句 |
| 主题翻译 | 20 min | 给一句中文 + 2–3 个关键词，写英文，对照参考句与搭配说明 | 把批改过的表达搬进自己的句子 |
| 复盘 | 5 min | 按模块进入（语法 / 小作文 / 主题翻译 / 大作文 / 观点），每条可存打磨版 | 纠错闭环 |

> 第三块原先是「大作文逻辑」，现在换成**主题翻译**（每天 8 句，按间隔把弱的推回来）。大作文逻辑挪到下方「加练」，四步流程一条没删，只是不计入每日四块。

题库有两层：**48 句语法 + 11 条小作文直接来自本人原文**（折线图/柱状图/饼图/两张表格），会优先出题；其余 60 句语法和 2 条小作文（流程、地图）是通用补充。

规则：

1. **对照不是判卷。** 词级重合率只说明「和参考差多远」，语法对不对还是你自己判；所以自评按钮只有三个：写对了 / 差一点 / 不会。
2. **语法题循环出。** 今天写错的，1–2 天后会再出现；写对的按 1/2/4/7/15/30 天往后推。
3. **大作文不写全文。** 加练里的「大作文逻辑」一题只练「审题 → 立场 → 论点链」，全文留给周末整篇模拟，否则每天 45 分钟不够。
4. **复盘按模块走。** 写作首页「复盘」先选块，再逐条打磨；一条能存两版：你当时写的、打磨后的。
5. **打磨要落到句子。** 「下次注意」没用，「把 the 补上」才有用。

### 我怎么批改

写作记录存在本机，导出方式：写作首页 → **导出写作记录**，得到 `ielts-writing-日期.json`，发给我。我会按「原句 → 最小修改 → 错因 → 一句话规则」回填，并把反复出现的错因（冠词、比较结构、中式搭配）整理成下一批语法题。

### 加练（不计入四块）

写作首页底部有两个短练习，适合「今天不想写整篇」的时候做：

- **成篇套模板（约 25 分钟）**：先花 90 秒想两个论点，再判题型（观点 / 双边讨论 / 利弊 / 问题解决 / 两问），然后一页写完全篇。
  每一段卡片上半是**参考**，分三层：① 这一段写几句、每句干什么；② **整段句式 3 选 1**——三个完整段落骨架，点一个、再点按钮，骨架就落进下面那个框，槽位是【论点句】这样的中文方括号，直接在同一个框里改掉；③ 折叠的「这段拆成四层看」（是什么 / 为什么两步 / 一个画面 / 所以呢，每层带例句和没话讲的三条路）与「一段完整示范」。
  下半**只有一个框**，一段一框：套了句式就在框里改，不套就自己写。方括号没换掉时，框下会提示「还有 4 处【方括号】没换成自己的内容」；同一篇里两段选了同一个句式，段头红字提醒换一个。
  下半是**一个文本框**，想自己写就自己写，用了句式也能改。九个段型各备三套句式，五类题型段落顺序不同，所以同一篇里不会两段长一个样。
  写完框下自动粗检：是不是只有一句结论、有没有写「为什么」、有没有具体的人或数字。整篇页再汇总一遍「哪段还是空的 / 哪段没写为什么」，点一下回去补。
  句式分两档：整段句式是考官腔（`The primary justification for this position is that …`），四层里的短积木是可自己拼的（`because / once / which in turn / as a result / Take … / That is why …`），先套整段，熟练了再自己拼。
- **观点速练（3 题）**：90 秒内想两个论点，再看观点库的论点、理由、例子。练「有话说」，不写整篇。题库 16 个话题，按间隔重复回来。

#### 每段为什么只写「是什么」会卡

原来每段给一个完整长模板，只填内容块，写出来必然是「一句结论 + because + 一个例子」——模板里没有位置放「怎么发生的」。现在每段的参考固定四层：

| 层 | 问自己 | 写不好会怎样 |
| --- | --- | --- |
| 是什么 | 这段证明什么，一句话 | 没有这层，这段就没有方向 |
| 为什么（两步） | 第一步谁做了什么 → 第二步因此变了什么 | 只写一步，就是「有结论没推导」 |
| 一个画面 | 一个人 + 一个地点 + 一个动作 | 没有这层，全是抽象名词，考官看不到具体 |
| 所以呢（可省） | 这句怎么拉回立场 | 硬凑反而重复开头 |

「没话讲」的提示只给中文，不给英文句子：为什么层给三条路（机制 / 反过来想 / 比一比），画面层给三条（换成人 / 加地点 / 加一个小数字）。参考里的例句一律用**另一道题**的内容，避免直接抄。

### 二次填空 · 把成篇改成高分版（复盘里的第五步）

入口：成篇套模板首页 / 成篇记录页 / 成篇复盘页，都有「二次填空」的按钮；也可以直接用 `#cloze` 打开，`#cloze=<id>` 直达某一篇，`#cloze=<id>/ref` 直达对照页。

它解决的是「批改完了，下次还是那么写」。做法是把一篇改到高分的范文拆成两半：

- **橙红色**是句式（让步转折、假拟分裂句、倒装、名词化这些位置固定、可以直接搬走的骨架）；
- **黑色空格**是你填的内容，点一下就能写，写进去就是正常字色，像自己写的作文。

每一段上方还有**整段中文译文**，中文里的横线和下面的英文空一一对应，点中文横线会跳到对应英文空。所以正确的做法是：先读中文，照着它把英文默写出来，再点对照看差在哪——比直接看英文填空记得牢。右上「收起中文」可以切回纯英文模式（选择会记住）。

空格里常驻灰色「中文提示」，写进去就消失，提示的是这一处该表达什么，不是答案。

只填短语、不写整句，所以每个人填出来都不一样，不存在抄范文。填完点「对照参考」：

- 和你一致几空、措辞不同几空、还没填几空，只报数，**不判对错**；
- 每处不同的下面写「为什么这么写」，这是这一屏真正有用的部分；
- 每条差异都带原文的中文提示，回看时不用翻回英文找位置；
- 底部列出本篇带走的语块（blunt instrument / razor-thin margins / at scale / on paper / signal virtue）。

题库在 `cloze.json`（每段 `segs` 是英文，`cn` 是同一套 `k` 的中文，所以能严格对齐），进度存在 `ielts.essay.cloze.v1`，中文显示偏好存在 `ielts.essay.cloze.cn`，和单词、写作、句型卡的键互不影响。

**提示怎么写**：`h` 一律写**中文原意**，照着就能翻成英文（如「二十年」「低收入家庭」「另一方面」），不写「什么样的支持」「一句收口的对比」这种解释性的元话语——那种提示是在考你猜谜，不是在考翻译。

| `line-graph-internet` | Task 1 线图 | 16 | 入门：只用 rise / reach / remain 这类描述数据的词 |

### 词组升级 · 二次填空的第三个视图

入口在二次填空列表页顶部（「第三个视图 · 6 个主题 · 24 题」），也可以直接开 `#cloze=up`，`#cloze=up/<题id>` 直达某一题。

一题给三样东西：

1. **原句**——一句平淡但语法正确的句子，就是考场上随手写出来的那种；
2. **三个必用词组**——每个给词性、中文义、搭配提醒（如 harm 的介词固定用 to，不能写 harm for）；
3. 你把这句**重写成一句更像考官写的话**，三个词组必须都用上。

写完点「对照参考」，给的是：三个词组逐个打勾（用上了 / 这句里没找到）、参考升级句、**为什么这样组织**（哪个词组占谓语、哪个占从句，句子才不会散）。再自评三档，记进 `ielts.essay.kw.v1`。

**不判对错、不打分**，只看两件事：词组有没有落下、搭配和介词对不对。整句怎么排是你自己的事——所以练的是造句语法，不是凭空造句，也不是逐词翻译。

题库在 `upgrade.json`，6 组 × 4 题，共 72 个词组：环境 / 教育 / 科技与媒体 / 政府与公共资金 / 工作与职业 / 广告与商业。

### 主题翻译 · 写作第三块

写作首页第三块。每天 8 句，一句一句来：

1. 给**一句中文** + 2–3 个关键词（如「执行 / enforce」）；
2. 你用英文写一遍；
3. 点「对照参考」，看参考英文、词级重合、以及**为什么这么写**（只讲搭配和介词，不讲玄学）；
4. 自评三档（写对了 / 差一点 / 不会），按 1/2/4/7/15/30 天复习。

题库在 `translate.json`，**104 句、13 个主题**：前 6 组是自拟句（环境 / 数据 / 工作 / 教育 / 商业与广告 / 政策与社会），后 7 组是从桌面范文里按主题批次抽出来的原句改写（广告 / 教育·范文 / 科技与媒体 / 政府与公共资金 / 动物与自然 / 犯罪与安全 / 城市与生活），每句 `src` 标了出处。

句式控制在**主谓宾 + because/so** 这一档，没有倒装、假拟分裂句和生僻比喻；`why` 只写能马上用上的规则，比如「be made from 用于看不出原形的原料」「by 接幅度，to 接最终数值」。

每轮抽题会先保证**每个主题各一句**，再补满 8 句，避免一晚上全是环境题。

### 复盘设计流程（五步）

| 步 | 在哪做 | 做什么 | 产出 |
| --- | --- | --- | --- |
| 1 精批 | 对话 / 写作-复盘 | 按六类标签找病因（搭配 / 中式 / 逻辑 / 任务 / 句法 / 语域） | 逐条「原句 → 改写 → 为什么」 |
| 2 骨架 | 成篇套模板 | 判题型 → 每段选一个整段句式落进框里改，或自己写整段 | 一篇完整初稿 |
| 3 填空 | 二次填空 | 先读整段中文，照着它写英文；句式由题给 | 一篇自己写的高分版 |
| 4 对照 | 二次填空 | 看每一处为什么这么写，收货语块 | 差异清单 + 5 个语块 |
| 5 存档 | 二次填空 / 成篇记录 | 存成「已对照」，三天后收起英文、只看中文再写一遍 | 可复现的记录 |

页面上每个视图顶部都有这五步的进度条，当前位置会亮起来。规则只有一条：**第 3 步不许写整句，第 4 步不许只看分数**。

前五步解决「这一篇怎么写好」，写作模块的**主题翻译**和二次填空的**词组升级**解决「下一篇还能不能写出来」——一个练整句（中文→英文），一个练句内组织（拿三个词组重造一句），都是把精批里学到的东西重新产出一遍。

| --- | --- | --- | --- |

抽句的规则：一句只留一个可迁移的骨架（判断句、让步句、因果句），删掉具体数据和人名；`src` 标出处，方便回头对原文。同一个主题的 8 句通常来自 1–4 篇范文，按原文的论证顺序排下来，不是零散好句——做题时能看出「先立论、再让步、最后回扣」这条线。

## 句型卡（单独一个入口）

首页「句型卡」，与背单词、写作分开计进度。两件事：

1. **模板句型**：12 个 Task 1 骨架（动态图 5、静态图 4、表格 3），每个骨架换 **3 个不同主题**（教育/环境/科技/交通/酒店…）各写一遍。练的是「结构不变、内容随便换」，不是背某一篇。
2. **词汇升级**：40 条基础 → 高级映射（increase a lot → surge、important → crucial、because → due to…），题干给中文情境和基础表达，你要写出用高级版的完整句子。

每天的节奏：**1 个句型（3 个主题）+ 8 条升级**，约 15 分钟。写错的按 1–2 天回来，写对的按 1/2/4/7/15/30 天往后推。

句型卡的进度键是 `ielts.pat.v1`，和单词的 `ielts.srs.v2`、写作的 `ielts.write.v1` 互不影响，清一项不会丢另一项。

## 手机和电脑怎么合并

进度存在**各自浏览器**里，不会自动同步。两边都练过的，用「全量导出 + 导入合并」：

1. 电脑上打开同一个网址，设置 → **全量导出**，得到 `ielts-all-日期.json`。
2. 把文件传到手机（微信文件传输 / 隔空投送 / 存到「文件」）。
3. 手机上打开 PWA → 设置 → **导入并合并** → 选这个文件。

合并规则：同一张卡阶段高的赢；日志取并集；打磨版保留；同一天的完成数取大的。**不会覆盖**手机上已有的进度，重复导入也不会产生重复记录。

> iOS 主屏 PWA 的存储和 Safari 是分开的，导入要在你平时用的那个图标里做。

**方法一（网页）**：仓库里点开 `deck.json` → 右上铅笔图标 → 全选删掉 → 粘贴新内容 → Commit。

写作题库更新同理：改 `writing.json` 后重新部署，并把 `sw.js` 里的 `CACHE` 版本号 +1，手机才会拿到新文件。

## 几个技术细节

- 发音用系统 TTS（iOS 的英文语音），不需要联网
- 间隔算法：不会 → 明天；模糊 → 按当前阶段；会了 → 1/2/4/7/15/30/60 天
- 写作题对照用词级 LCS 比对，只标「漏了哪些词 / 多了哪些词」，不判语法
- 进度导出：设置 → 导出进度 JSON（可发给我合回 Notion）
- 换手机/清缓存会丢进度，**建议每周导出一次**

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 主界面：背单词、刷错题、写作入口 |
| `writing.js` | 写作模块：今日四块、计时、对照、写作 SRS（第三块是主题翻译） |
| `writing.json` | 写作题库：108 句语法、13 条小作文骨架、10 道大作文 |
| `translate.json` | 主题翻译题库：104 句 / 13 主题，每句带关键词提示、参考英文、搭配说明与出处 |
| `patterns.js` | 句型卡模块：骨架 × 主题、词汇升级、独立 SRS |
| `patterns.json` | 句型题库：15 个骨架 × 3 个主题、40 条词汇升级 |
| `ideas.js` | 观点速练：90 秒两论点、独立 SRS |
| `ideas.json` | 观点库：16 个话题 × 2 个论点（含理由与例子） |
| `essay.js` | 成篇套模板：判题型 → 每段「整段句式 3 选 1 + 四层参考 + 大框自写」→ 整篇自查 → 复盘 → 二次填空 / 词组升级 |
| `essay.json` | 5 类题型路由 + 9 个段型；每段型带 3 个整段句式（`tpl.frames` + 四个槽位）与 3–4 层拆解（`layers`，每层带问题、短句式、例句、三条思路） |
| `cloze.json` | 二次填空题库：高分范文拆成「句式 + 空格」，每段附整段中文译文（`cn`，与英文共用同一套 `k`） |
| `upgrade.json` | 词组升级题库：6 组 × 4 题，每题一句平淡原句 + 3 个必用词组（含词性、中文义、搭配提醒）+ 参考升级句 |
| `deck.json` | 词库快照，由 Notion 导出 |
| `sw.js` | 离线缓存（`deck.json` / `writing.json` / `translate.json` / `upgrade.json` 等题库走网络优先） |
| `manifest.webmanifest` | 主屏图标与全屏配置 |
